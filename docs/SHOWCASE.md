## 📌 Boilerplate (50–100 words)

Sudarshana Chakra is a self-evolving, multimodal personal AI desktop environment
for Windows. Built on PyQt6, it runs an autonomous plan→execute→replan loop over
100+ real desktop tools: browser automation, Office document generation,
geospatial mapping, music control, hardware circuit vision, and five enterprise
business verticals. When it lacks a tool, it synthesizes, sandbox-tests and
hot-loads a new one. A background sentry repairs its own runtime crashes. It is
local-first — keys, memories and data stay on the user's machine.

## 🎬 5 Standout Workflow Demos

1. **Voice → Action** — *"Create a project roadmap spreadsheet"* → Sudarshana
   opens Excel and fills structured rows. (Shows autonomy, not chat.)
2. **Self-Evolution** — ask for a task it has no tool for → it writes a new
   Python tool, tests it in the "Crucible" sandbox, and uses it instantly.
3. **Browser Automation** — *"Find flights Mumbai to London"* → drives your real
   logged-in Chrome via Playwright/CDP and returns results.
4. **Self-Healing** — a runtime error appears → the sentry traces it, patches the
   source, and shows a repair telemetry card — no crash.
5. **Business Vertical** — *"Add 200 units of SKU-42 and export low-stock"* →
   encrypted local DB write + Excel export.

## ❓ FAQ for press

**Is it free?** Source-available; free to run for one personal installation (see
`LICENSE`). Support by starring the repo.

**Is it safe?** Sandboxed tool execution, AST validation, permission sentries,
path-traversal and prompt-injection defenses. Powerful tool — run on your own PC.

**Windows only?** Yes, deliberately.

**Does it need an API key?** No for local features; a free Gemini key enables
voice + vision.
